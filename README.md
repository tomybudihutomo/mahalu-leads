# Mahalu Leads

Internal lead management tool for Mahalu Spa.

## Features
- Manual lead entry directly in table
- Instagram Lama / Instagram Baru / TikTok / Walk-in sources
- Organic vs Ads attribution
- Follow-up, Deal, and Tidak Deal status
- Lost reason tracking
- Manual ad spend input
- Conversion, CPL, CPA, and ROAS dashboard

## Stack
Static HTML/CSS/JavaScript + Supabase + Vercel.

## Database
Uses the existing Mahalu Supabase project with separate `leads_*` tables. HPP tables are not modified by this application.
